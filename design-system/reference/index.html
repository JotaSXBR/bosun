Static specimens exported from the design system. Each link opens a standalone HTML page.

Brand

  • Connection motifDotted lines linking nodes — modules working together. Use in marketing & onboarding only, never inside work areas.
  • PatternsHatch = planned / remaining. Dots = current / in motion. Grid = precision backdrop. Classes: .bx-hatch .bx-dots .bx-grid
  • Voice — microcopyCalm, competent, direct. Short sentences, clear verbs, useful information. Nautical only in brand moments.
  • Wordmark (interim)No logo file supplied — the name is set in Manrope ExtraBold +6% tracking. Do not draw a symbol.
  • IconographyLucide line icons, 1.5px stroke, round caps — shipped as SVGs in assets/icons and via the Icon component.

Colors

  • Abyss & OceanDark structural blues — page, cards, raised layers, controls. 900 and ocean-700 are brand.
  • Brand paletteThe six named brand colors. Core pairing: Azul abissal + Branco névoa + Verde sinal.
  • Data paletteCharts lead with Verde sinal, support with névoa and ocean; Âmbar only flags. Hatch/dots carry meaning before hue.
  • Light theme[data-theme=light] — Branco névoa page, white cards, Azul abissal ink. Same components, no overrides.
  • Névoa & AçoNeutrals. Mist = light page & dark-theme ink; steel-400 = muted text on dark; steel-500 (brand) = icons/meta only.
  • Status colorsSoft tint + full-strength ink. Âmbar is the only warning color; running reuses Verde sinal.
  • Verde sinalAccent scale. 400 is brand: selection, primary action, live data. Text on it is always Azul abissal.
  • Surface layers (dark)Depth is tonal: each step closer to the user is a little lighter. No borders between layers.

Spacing

  • Notched card anatomyTab + body share one surface; actions sit in the cut, 8px off the edges; 16px concave fillet; 24px radius & padding.
  • ElevationTonal first. Shadows only for controls (hairline highlight) and floating layers (pop).
  • MotionCalm and precise: short eased transitions, no bounce, no overshoot. Charts grow in 640ms.
  • Corner radiiSoft-geometric. Cards 24, nested 18, inputs/menus 14, chips & buttons fully round.
  • Spacing scale4px base. 16 between cards, 24 inside cards, 8 between grouped controls.

Type

  • Interface — InterInter for all UI copy. 14px is the working size; 16px for reading; 12px for meta.
  • Display — ManropeTwo-weight headline: Light lead-in in muted ink, SemiBold payoff in strong ink. Tight tracking.
  • Heading scaleManrope 600 for page/section titles, 500 for card titles. Sentence case always.
  • MetricsBig numbers in Manrope Light, tabular, units at 40% size in muted ink.
  • Technical — JetBrains MonoIDs, run logs, keyboard shortcuts, timestamps in logs. Never for headings or prose.
